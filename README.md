### VÉRTICE Hub
E-commerce full stack com **autenticação, catálogo, carrinho, checkout, pagamentos, pedidos e painel administrativo**.

**Stack:** React · TypeScript · Express · Prisma · PostgreSQL · Mercado Pago · PayPal

### ZapBebidas
